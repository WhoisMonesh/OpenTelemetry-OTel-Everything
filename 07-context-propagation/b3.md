# B3 Propagator

## What It Is
The **B3 propagator** supports Zipkin's `b3` / `X-B3-*` headers for backward compatibility with Zipkin-based systems.

## Why It Exists
Many legacy services and some proxies speak B3. The B3 propagator lets OTel interoperate with them during migration.

## Headers
```
X-B3-TraceId: 4bf92f3577b34da6a3ce929d0e0e4736
X-B3-SpanId:  00f067aa0ba902b7
X-B3-Sampled: 1
```
(single-header `b3: <trace>-<span>-<parent>-<sampled>` also supported)

## Architecture
```mermaid
graph LR
    A[OTel app] -->|X-B3-*| Z[Zipkin/legacy]
```

## When to Use It
- Interop with Zipkin or B3-only services
- During gradual migration to W3C

## Code Example (Java)
```java
propagatorsConfig.setPropagators(TextMapPropagator.composite(
    B3Propagator.getInstance(), W3CTraceContextPropagator.getInstance()));
```

## Best Practices
- Prefer W3C for new services
- Use B3 only where required
- Combine via composite propagator
